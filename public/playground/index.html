eHagakiの投稿欄を組み込んで試す

eHagakiの投稿欄（Composer）は、iframe、Full Web Component、Host-owned Composer Liteの3つの方式でほかのページやNostrクライアントに組み込めます。方式ごとのページで、実際に組み込んだ状態の動作、公開API、イベントを確かめられます。

埋め込み・統合ガイドを読む 方式の選び方
iframe

iframe

  • eHagakiを別のページとしてそのまま埋め込む
  • 別originで配信すれば、ホストのJavaScriptから隔離できる
  • 親クライアント連携ログイン、storage / IndexedDBの委譲を使える
iframeを試す
Full Web Component

Full

  • 同じdocumentに <ehagaki-composer> を置く
  • 認証・Relay・アップロード・署名・publishまでeHagakiが受け持つ
  • NIP-07はホストの window.nostr を使い、NIP-46も使える
Fullを試す
Host-owned Composer Lite

Lite

  • 投稿欄の編集UIとメディア処理だけを組み込む
  • eventの構築・署名・publishはホストが受け持つ
  • アカウントやsignerを持つ既存のNostrクライアント向け
Liteを試す

方式の選び方

上から順に確認し、最初に当てはまった方式を選んでください。

  1. アカウント、signer、event構築、publishをホストがすでに持っている→ Host-owned Composer Lite。投稿欄だけを借りて、投稿処理はホストで行います。
  2. ホストのJavaScriptと実行環境を分けたい、または親クライアント連携やstorageの委譲を使いたい→ iframe。隔離が必要な場合は、ホストとは別のoriginから配信してください。
  3. 認証から投稿までeHagakiに任せて、同じページに直接置きたい→ Full Web Component。eHagaki自身が署名してpublishします。

3方式の比較

項目iframeFullLite
境界別document・別Window realm。originを分けられる同じdocument・同じWindow realm（Shadow DOM）同じdocument・同じWindow realm（Shadow DOM）
認証eHagakiまたは親クライアントeHagaki（NIP-07 / NIP-46）。ローカルnsecは使えないホスト。Liteは認証を持たない
署名・publisheHagaki。親クライアント連携時は署名を親へ委譲eHagakiホスト
データの受け渡しpostMessage のembed protocolメソッド、プロパティ、CustomEventメソッド、submit / uploadMedia コールバック
見た目URLクエリ、settings.setCSS Custom Properties、内部の設定画面CSS Custom Properties

Web Componentはホストと同じWindow realmで動くため、ホストのJavaScriptから秘密情報を隔離する目的には使えません。詳しくは 埋め込み・統合ガイド を参照してください。

最小構成のコード

そのままコピーして、組み込みの出発点にできます。

<iframe
  src="https://lokuyow.github.io/ehagaki/"
  width="600"
  height="400"
  title="eHagaki Composer"
></iframe>
<script type="module" src="https://lokuyow.github.io/ehagaki/web-component/ehagaki-composer.js"></script>
<div style="height: 580px">
  <ehagaki-composer
    asset-base="https://lokuyow.github.io/ehagaki/web-component/"
  ></ehagaki-composer>
</div>

<script type="module">
  const composer = document.querySelector('ehagaki-composer');
  await composer.whenReady();
</script>
<div id="composer-mount" style="height: 580px"></div>
<script type="module">
  await import('https://lokuyow.github.io/ehagaki/web-component/host-owned/ehagaki-composer.js');

  const composer = document.createElement('ehagaki-composer');
  composer.assetBase = 'https://lokuyow.github.io/ehagaki/web-component/host-owned/';
  composer.configureHostOwned({
    async submit(output, { signal }) {
      // outputからホストがeventを作り、署名してpublishする
      void output;
      void signal;
      return undefined;
    },
  });
  document.querySelector('#composer-mount').append(composer);
  await composer.whenReady();
</script>

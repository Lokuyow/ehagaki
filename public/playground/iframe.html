iframe Playground

このページが親クライアントになり、eHagakiをiframeで埋め込んで、embed protocol v1のメッセージを中継します。親ページでのNIP-07ログイン、返信・引用・チャンネルの指定、設定の同期、storageの委譲を試せます。

  • ホストのJavaScriptから隔離したい
  • 親クライアント連携でログインしたい
  • storage / IndexedDBを親へ委譲したい

1

親クライアントでログインする

NIP-07でログインすると親ページの window.nostr を使い、秘密鍵でログインするとこのサンプルに保存した秘密鍵で署名します。iframeからの署名要求は親が処理します。

秘密鍵ログインは動作確認専用です

秘密鍵でログインすると、このサンプルはnsecを親ページのlocalStorageに平文で保存します。ログアウトすると削除します。NIP-07ログインと秘密鍵ログインは同時に使えないため、切り替えるときはいったんログアウトしてください。

2

返信・引用・チャンネルを指定する

指定したrelayの最新のkind 1を表示します。返信・引用・本文は、iframeのready後なら postMessage で同期し、未接続のときだけURLクエリを付けて読み込み直します。

ws:// または wss:// のrelayを入力し、「タイムライン更新」を押してください。使ったrelayは次の入力候補に保存します。

タイムライン未接続
reply: なし / quote: 0 件 / channel: なし

本文を同期する

返信・引用・チャンネルを付けたまま、本文だけを差し替えられます。iframeからは requestId 付きで composer.contextApplied / composer.contextError が返り、iframe側での変更は composer.contextUpdated で親に届きます。

パブリックチャット（channel context）

channel referenceには nevent1... を使ってください。channel relaysは、読み込み直すときは channelRelays クエリとして、実行中に更新するときは payload.channel.relays として渡します。relaysを省略してevent idだけを渡すと、iframeがkind 40 / 41からmetadataとrelaysを解決します。relaysを省略してname / about / pictureだけを渡すと、iframe自身のwrite relayを使います。

3

初回設定と実行中の同期

embed~ のクエリ（embedLocale=en、embedTheme=dark、embedAccentColor など）は、iframeを起動するたびに強制されます。初期値だけを渡したいときは default~（defaultLocale=en など）を使います。常に表示しておくiframeでは、ready後や親の設定が変わったときに settings.set を送れば、読み込み直さずに同期できます。ユーザー設定は親のstorageに保存されますが、実行中に強制したカラーは保存されません。

4

URL・origin・一時Relay Config

iframeに読み込むeHagakiのURLです。書き換えたら「iframe を再読み込み」を押してください。

Host-provided temporary Relay Config

有効にすると、iframeはready前に relays.request を送り、親は同じrequestIdで relays.set を返します。値を変えたらiframeを読み込み直してください。

イベントログ

iframeとの間でやり取りしたメッセージを、新しい順に記録します。

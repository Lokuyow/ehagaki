# eHagaki v1.34.0 リリースノート

v1.33.0 以降の変更（#553〜#596）をまとめました。

## 新機能

- **公開鍵のみのログイン（読み取り専用）に対応**しました（#580）。
- **オフラインでもメンション候補に Nostr プロフィールを出せる**ようにしました（#579）。
- **メディアギャラリーにホバー時のページ送り矢印**を追加しました（#585）。
- 投稿履歴の全件スキャンで **NIP-77** を使えるようにしました（#569）。
- **AVIF の元画像をそのままアップロード**できるようにしました。Blossom の MIME チェックの対象も広げました（#577）。
- 投稿履歴の更新ボタンに、更新中のスピナーを表示します（#567）。
- 投稿履歴のリポスト行で、すべての操作を表示します（#568）。
- テスト版の PWA 名とアイコンを本番と区別し、ヘッダーの TEST 表示、OGP の「eHagaki Test」表記と専用画像も揃えました（#554, #555, #556, #557）。

## 改善

- 投稿履歴・通知のハッシュタグを、外部クライアントで開けるようにしました（#589）。
- 投稿履歴・通知・宛先指定で、長いメンション名を省略表示します（#584）。
- メンション候補と本文のプロフィール画像を拡大しました（#581）。
- 通知欄と投稿履歴のリアクション内訳で、1 件のときの数字を非表示にしました（#559）。
- 通知ダイアログで、元投稿を先に表示します（#561）。
- 上部メディアギャラリーのサイズを、画面幅に合わせて変えるようにしました（#573）。
- 投稿プレビュー間でメディアギャラリーを共有します（#576）。
- 画像のクロップで、ギャラリー内のズーム範囲を制限しました（#582）。
- 手動再取得時の進捗トーストを廃止しました（#571）。
- キーボードのボタンバーの追従を滑らかにし、開閉時のスライドを調整しました（#593, #594）。
- NIP-07 のログイン復元で、再読み込み時の待ち時間を延ばしました（#578）。
- Nosskey アカウントの保存形式を、先に読み取れるようにしました（#586）。

## パフォーマンス

- 投稿履歴・通知の再描画と重複計算を減らしました（#558, #591）。
- 投稿履歴のスクロール時、古い投稿をより早く先読みします。ダイアログ内の一覧では先読みを共有します（#565, #566）。
- 投稿履歴の件数を IndexedDB のインデックスで集計して高速化しました（#562）。
- 変更のない履歴イベントでは、完全検証の結果を再利用します（#564）。
- 共有先の投稿が見つからないリポストは、履歴スキャンから外しました（#563）。
- 入力・スクロール・初期ロード・画像処理の負荷を軽減しました（#588）。
- 初回起動で読み込むエントリ JS を減らしました（#592）。
- 画像は、キャッシュ書き込みを待たずに返します（#574）。
- 保存済み投稿メディアの読み出しを、URL ごとのロックで制御します（#575）。
- プロフィール・絵文字・投稿メディアのキャッシュに上限を設けました（#572）。
- 通知一覧の再計算を減らし、投稿履歴と仕組みを共有しました（#551）。
- NIP-46 は、起動時の復元で signer の応答を待たずにログイン状態にします。ログイン・復元の所要時間はフェーズ別に debug ログへ出します（#549, #550）。
- 投稿フッターのツールチップは、初回操作まで生成しません（#548）。
- 投稿履歴の描画で、日時フォーマッタとメッセージ部品の生成を減らしました（#547）。
- スレッドグラフが変わっても、変更のないスレッド状態は安定させました（#546）。
- スレッドカードが、センシティブ本文のローダーを再利用して再購読しないようにしました（#545）。

## 不具合修正

- 投稿履歴・通知のメンションが npub に戻る問題を修正し、アイコンも表示します（#590）。
- Android PWA で、エディタがキーボードバーから離れる問題を修正しました（#583）。
- キーボード開閉時のエディタのはみ出しと画面のずれを修正しました（#594）。
- 履歴の移行中でも、更新後にログインを復元できるようにしました（#553）。
- 返信先の読み込み中に別の返信先を開くと、先の返信先が表示されない問題を修正しました（#544）。
- 以前の返信先でインデントが復元されない問題を修正しました（#570）。
- 履歴の関連投稿を解決している間に、スクロール位置が失われる問題を修正しました（#560）。

# eHagaki v1.34.0 リリースノート

v1.33.0 以降の変更（#553〜#596）をまとめました。

## 新機能

- 公開鍵だけでログインできるようになりました。このログインは読み取り専用です（#580）。
- オフラインでも、メンション候補に Nostr のプロフィールを表示します（#579）。
- メディアギャラリーに、前後へ切り替えるホバー用の矢印を追加しました（#585）。
- 投稿履歴の全件スキャンで NIP-77 を使えるようにしました（#569）。
- AVIF 画像を、元のままアップロードできるようにしました。Blossom 向けの MIME チェックの対象も広げました（#577）。
- 投稿履歴の更新ボタンに、更新中を示すスピナーを表示します（#567）。
- 投稿履歴のリポストの行で、すべての操作を表示します（#568）。
- テスト版を本番と見分けやすくしました。PWA の名前とアイコン、ヘッダーの TEST 表示、OGP の「eHagaki Test」の表記と専用画像が、本番とは別になります（#554, #555, #556, #557）。

## 改善

- 投稿履歴と通知のハッシュタグを、外部クライアントで開けるようにしました（#589）。
- 投稿履歴・通知・宛先指定で、長いメンション名を省略して表示します（#584）。
- メンション候補と本文のプロフィール画像を、大きく表示します（#581）。
- 通知欄と投稿履歴のリアクション内訳で、1 件のときは数字を表示しません（#559）。
- 通知ダイアログで、元の投稿を先に表示します（#561）。
- 上部のメディアギャラリーの大きさを、画面幅に合わせて変えるようにしました（#573）。
- 投稿のプレビュー同士で、メディアギャラリーを共有します（#576）。
- 画像のクロップで、ギャラリー内の拡大できる範囲を制限しました（#582）。
- 手動で再取得したときの進捗トーストを、表示しないようにしました（#571）。
- キーボードのボタンバーの追従を滑らかにし、開閉時のスライドも調整しました（#593, #594）。
- NIP-07 でのログイン復元は、再読み込み後により長く待つようにしました（#578）。
- Nosskey アカウントの保存形式を、先に読み取れるようにしました（#586）。

## 動作が軽くなった点

- 投稿履歴と通知の表示を軽くしました。再描画と重複した計算を減らし、件数の集計も速くしました（#547, #551, #558, #562, #591）。
- 投稿履歴をスクロールするとき、古い投稿を早めに先読みします。ダイアログ内の一覧では、この先読みを共通にしました（#565, #566）。
- 変更のない履歴イベントは、検証をやり直さず前回の結果を使います（#564）。
- 共有先の投稿が見つからないリポストは、履歴のスキャンを省きます（#563）。
- 入力、スクロール、初期ロード、画像処理の負荷を減らしました（#588）。
- 初回起動で読み込む JavaScript を減らしました（#592）。
- 画像は、キャッシュへの書き込みを待たずに表示します（#574）。
- 保存済みの投稿メディアは、URL ごとのロックで読み出します（#575）。
- プロフィール、絵文字、投稿メディアのキャッシュに上限を設けました（#572）。
- NIP-46 では、起動時のログイン復元で signer の応答を待たず、ログイン状態にします（#549, #550）。
- スレッドの表示で、変更のない部分の再計算を減らしました（#545, #546）。
- 投稿フッターのボタンのツールチップは、初めて操作するまで作りません（#548）。

## 不具合修正

- 投稿履歴と通知で、メンションが npub に戻る問題を修正しました。アイコンも表示します（#590）。
- Android の PWA で、エディタがキーボードのボタンバーから離れる問題を修正しました（#583）。
- キーボードの開閉時に、エディタがはみ出したり画面がずれたりする問題を修正しました（#594）。
- 履歴の移行中でも、更新後にログインを復元できるようにしました（#553）。
- 返信先の読み込み中に別の返信先を開くと、先の返信先が表示されない問題を修正しました（#544）。
- 以前の返信先でインデントが復元されない問題を修正しました（#570）。
- 履歴の関連投稿を解決している間に、スクロール位置が失われる問題を修正しました（#560）。

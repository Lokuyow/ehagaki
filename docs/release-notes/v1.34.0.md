# eHagaki v1.34.0 リリースノート

v1.33.0 以降の変更（#553〜#596）をまとめました。

## 新機能

- **公開鍵で閲覧専用ログイン**：ログイン画面の秘密鍵の欄に `npub` か `nprofile` を入力すると、閲覧専用でログインできます。プロフィール、投稿履歴、通知を見られます。投稿などの署名はしません。公開鍵でログインしている間は、左下のアイコンとプロフィール画面にそのことを表示します（#580）。
- **オフラインでもメンション候補**：端末に保存してあるプロフィールから、オフラインでもメンション候補を出します。候補は文字を入力してから表示し、全角の「＠」でも検索できます（#579）。
- **投稿履歴・通知の画像を横スクロールで表示**：投稿履歴、通知、引用や返信先のカードの画像と動画を、投稿画面と同じ横スクロールのギャラリーで表示します。マウスを重ねると左右に矢印が出て、1 画面分ずつ送れます。矢印は投稿画面のギャラリーにも出ます（#576, #582, #585）。
- **ハッシュタグから検索**：投稿履歴と通知の本文にあるハッシュタグを押すと、設定した外部クライアント（nostter、Jumble、Lumilumi、Primal）でそのハッシュタグを検索します。外部クライアントに njump かカスタムの URL を設定している場合は、リンクになりません（#589）。
- **リポストにも返信・引用・リアクション**：投稿履歴のリポストの行に、返信、引用、リアクション、メニューのボタンを並べました。リポストへの返信は、NIP-22 のコメントとして送ります。返信先と引用のメニューには「リポスト」を加え、チャンネル投稿のカードからも返信と引用ができます（#568）。
- **AVIF 画像をそのままアップロード**：AVIF 画像は、アニメーションを含めて元のファイルのままアップロードします。ファイル形式の情報が欠けた AVIF も判別できます（#577）。
- **全件スキャンで NIP-77 に対応**：投稿履歴の全件スキャンでは、NIP-77 に対応したリレーと手元の履歴を照らし合わせ、足りない投稿だけを取り寄せます。照合できないリレーでは、これまでの方法で取り寄せます。結果の画面では、すでにそろっていた場合と、リレーに投稿がなかった場合を分けて表示します（#569）。
- **テスト版を本番と見分けやすく**：テスト版の PWA の名前とアイコン、ヘッダーの TEST の表示、共有したときのプレビュー（「eHagaki Test」の表記と専用画像）を本番と分けました（#554, #555, #556, #557）。

## 改善

- **メンションの表示**：通知、投稿履歴、宛先指定で、長いメンション名を省略して表示します。メンション候補と本文のアイコンを大きくしました。メンションを押すと、設定した外部クライアントでそのプロフィールを開きます。メンションのボタンは @ アイコン付きの目立つボタンにしました（#581, #584）。
- **投稿履歴の更新中の表示**：リレーとの同期中と再取得中は、ヘッダーの再取得ボタンが回転する表示に変わります。「リレーと同期中...」「同期完了」「再取得中...」のトーストは出しません。再取得の結果と、同期に失敗したときの通知は、これまでどおり表示します（#567, #571）。
- **通知の表示**：元の投稿が端末に保存してあれば、リレーからの取得を待たずに表示します。リアクションの内訳では 1 件のときの数字を出さず、リポストの件数は 2 件以上のときだけ出します（#559, #561）。
- **一覧の読み込み**：通知は、端末に保存してある古い通知をスクロールに合わせて読み込みます。それより前の通知は、「もっと読み込む」ボタンでリレーから取り寄せます。メディアの一覧はスクロールで次のページを読み込み、下書きの一覧は 20 件ずつ表示します（#566）。
- **引用や返信先が後から表示されても位置を保つ**：投稿履歴で、引用、リポスト、返信先のカードが遅れて表示されても、見ている投稿の位置がずれないようにしました（#560）。
- **投稿画面のギャラリーの大きさ**：画面の幅に合わせて、高さ 180px（幅 360px のとき）から 320px（幅 560px 以上のとき）まで大きさが変わります（#573）。
- **キーボードの開閉**：キーボードを開いたり閉じたりしたときに、ボタンバーがエディタと同時に動くようにしました。エディタとバーの間に隙間ができたり、バーがちらついたりしません（#593, #594）。
- **NIP-07 のログインの復元**：再読み込みしたときに、拡張機能の応答を最大 10 秒待つようにしました。応答が遅い拡張機能でも、ログインが戻りやすくなります。時間切れになったときは、アカウントの選択を残したまま未ログインの表示にします（#578）。
- **キャッシュの上限**：プロフィール画像、カスタム絵文字、投稿メディアのキャッシュに上限を設けました（#572）。
- **Nosskey への準備**：今後の Nosskey ログインに備えて、保存済みのアカウント一覧に Nosskey のアカウントがあっても消さずに残します。このバージョンでは、Nosskey のアカウントには切り替えられません（#586）。

## 動作が軽くなった点

- **投稿履歴の追加読み込み**：スクロールで古い投稿を読み込むのが速くなりました。約 8 万件の履歴で試したところ、次の 50 件が表示されるまでの時間が 7.27 秒から 0.68 秒になりました。先読みを早めたので、読み込み中の表示もあまり出なくなります（#562, #563, #564, #565）。
- **投稿履歴と通知のスクロール**：スクロールや追加読み込みのときに、表示の作り直しや同じ計算の繰り返しを減らしました（#545, #546, #547, #548, #551, #558, #591）。
- **入力中の動作**：文字を入力するたびの処理と、候補ポップアップの作り直しを減らしました（#588, #591）。
- **起動**：初回起動で読み込むデータを減らしました（#588, #592）。
- **NIP-46 のログインの復元**：起動したときに、署名アプリの応答を待たずにログイン状態にします。署名が必要な操作のときだけ、応答を待ちます（#549, #550）。
- **画像の表示**：キャッシュへの保存が終わるのを待たずに、画像を表示します（#574, #575）。

## 不具合修正

- v1.32.0 から更新した直後、履歴の移行が終わるまでプロフィール欄が読み込み中のままになる問題を修正しました（#553）。
- 投稿履歴と通知で、メンションの名前が npub の表示に戻ってしまう問題を修正しました。メンションにはアイコンも表示します（#590）。
- Android Chrome の PWA で、メンション候補を開くとエディタとキーボードのボタンバーの間に隙間ができる問題を修正しました（#583）。
- キーボードを開いたときに、スクロールバーが一瞬出て画面がずれる問題を修正しました（#594）。
- 投稿履歴で返信先をたどったとき、カードが字下げされない問題を修正しました（#568, #570）。
- 返信先の読み込み中に別の返信先を開くと、先に開いた返信先が表示されない問題を修正しました（#544）。
